## 第 1 步：确认当前状态

先执行：

```
git status
```

### 作用

确认当前工作区是否干净。

如果显示：

```
nothing to commit, working tree clean
```

说明当前没有未提交的修改，可以继续查看历史。

------

## 第 2 步：查看简短提交历史

执行：

```
git log --oneline
```

### 作用

用最简洁的方式查看当前仓库的 commit 记录。

你应该能看到类似：

```
xxxxxxx Add Git new document workflow
990577e Split Git guide into separate docs
40ec3d8 Initial commit
```

含义是：

```
最上面的是最新提交
越往下越早
每一行左边是 commit 短哈希
右边是 commit message
```

------

## 第 3 步：查看更清楚的分支历史

执行：

```
git log --oneline --graph --decorate --all
```

### 作用

查看提交历史、分支位置、远程分支位置。

正常会看到类似：

```
* xxxxxxx (HEAD -> main, origin/main) Add Git new document workflow
* 990577e Split Git guide into separate docs
* 40ec3d8 Initial commit
```

其中：

```
HEAD -> main
```

表示当前本地所在分支是 `main`。

```
origin/main
```

表示 GitHub 远程仓库的 `main` 分支。

如果 `HEAD -> main` 和 `origin/main` 在同一个 commit 上，说明本地和 GitHub 已同步。
